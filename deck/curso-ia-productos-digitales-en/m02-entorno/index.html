THE PROBLEM

"It works on my machine"

Without a reproducible environment, every new collaborator — or you yourself on another computer — starts from zero.

Three different computers. Three versions of Node. Three versions of Python. Three different results for the same code.

The time lost to "it works locally but not in production" isn't an accident: it's the direct consequence of never having declared the environment as code.

“

The environment is part of the product. If it isn't versioned, it doesn't exist.

Modern development principle Infrastructure as Code · DevContainers
THE SOLUTION

The environment as code

Tools, versions, environment variables: all declared in files the AI can read, understand, and modify.

A devcontainer.json file defines exactly what software, what versions, and what configuration your project needs. There's no ambiguity.

The AI can read that file, understand the project's context, and act on it. Without that file, the AI works blind.

CHAPTER 02

Docker

The box that packages your environment and lets it travel without breaking.

DOCKER EXPLAINED

Why Docker changes everything

Docker is the pot with its own specific soil, nutrients, and microclimate. You can move it anywhere and the plant keeps living the same way.

Without Docker: your app works on your machine. On the server, it fails. Different dependencies, different versions, a different operating system.

With Docker: your app lives in a self-describing container. The server runs that exact same container. It works the same way every time, anywhere.

KEY CONCEPTS

The vocabulary of Docker

  • 01

    Docker Image

    The recipe. It defines what software the container includes: base operating system, languages, libraries, configuration. Immutable and versioned.

  • 02

    Container

    The recipe running. A live instance of the image. You can have ten containers of the same type running in parallel.

  • 03

    Dockerfile

    The text file that describes how to build the image, step by step. The AI generates and edits Dockerfiles for you if you ask it to.

  • 04

    docker-compose.yml

    The orchestra conductor. It coordinates multiple containers: your app, the database, the queue server. Everything starts with a single command.

INSTALLATION · DOCKER DESKTOP

Installing Docker on your system

🪟

Windows

  1. Enable WSL2 in Windows Features
  2. Download Docker Desktop from docker.com
  3. Install and restart
  4. Verify: docker --version
wsl --install
🍎

macOS

  1. Download Docker Desktop for Mac (choose Intel or Apple Silicon)
  2. Open the .dmg and drag it to Applications
  3. Launch Docker from Launchpad
  4. Verify: docker --version
brew install --cask docker
🐧

Linux (Ubuntu/Debian)

  1. Update packages
  2. Install Docker Engine
  3. Add your user to the docker group
  4. Verify: docker run hello-world
sudo apt install docker.io

✓ Test that it works: docker run hello-world — you should see "Hello from Docker!"

CLAUDE CLI

The Anthropic AI that acts on your project

Claude Code (CLI) turns your terminal into a development agent that can read, write, execute, and reason about your entire project.

It's not a chatbot. It's an agent that acts: it creates files, modifies code, runs commands, and reasons about the full context of the repository.

Requires an account on Anthropic Console with API credits (paid). It's the course's primary tool for anyone with a license.

Context window: 200k tokens. Multi-file. Support for CLAUDE.md and custom agents.

The key difference: it has a free tier. For anyone without a Claude license, Antigravity is the recommended alternative in this course.

Same concepts, same mechanics. The course examples will be shown first with Claude and then with Antigravity so you can follow along with either one.

VERIFYING THE ENVIRONMENT

How to know everything works

  • 01

    code --version

    Returns the VS Code version number. If the command isn't recognized, reinstall and check the "Add to PATH" option.

  • 02

    docker --version && docker run hello-world

    The first command verifies the installation. The second runs a test container. If you see "Hello from Docker", everything works.

  • 03

    claude --version / antigravity --version

    Confirms the agent is installed. If it fails, check that Node.js is in the PATH with node --version.

  • 04

    claude "say hello" / antigravity "say hello"

    The definitive test: the agent responds in natural language. If it asks for authentication, follow the login flow for the corresponding tool.

BEST PRACTICES

Environment variables and secrets

API keys are never written directly into code. Ever.

.env — stores secrets locally. This file NEVER gets pushed to Git. Add it to .gitignore from day one.

.env.example — documents which variables the project needs, with example values but no real ones. This one does get versioned.

The AI handles this pattern automatically if you tell it in CLAUDE.md: "never write API key values directly in the code, use environment variables".

COMMON PROBLEMS

Common errors and their solutions

THE SYMPTOM

What you see

  • Docker won't start when you run the first command
  • Error: address already in use (port taken)
  • claude: command not found
  • Error: API key not configured
THE FIX

What to do

  • Check that Docker Desktop is running (icon in the system tray)
  • Change the port in docker-compose.yml from 3000 to 3001
  • Install Node.js from nodejs.org first, then repeat npm install -g
  • Run claude auth login again and complete the flow in the browser
TROUBLESHOOTING

Four errors and their solutions

  • 01

    Docker won't start — Docker Desktop must be running

    The Docker CLI needs Docker Desktop running in the background. Look for the whale icon in the system tray. If it's not there, open it manually.

  • 02

    Port in use — change the port in docker-compose.yml

    If port 3000 is taken, edit ports: - 3000:3000 and change it to 3001:3000. The first number is the port on your machine.

  • 03

    Claude/Antigravity not authenticated — repeat auth login

    The session can expire. Run claude auth login or antigravity auth login and follow the flow in the browser.

  • 04

    npm not found — install Node.js first

    Visit nodejs.org, download the LTS version, and install it. Close and reopen your terminal before retrying any npm command.
