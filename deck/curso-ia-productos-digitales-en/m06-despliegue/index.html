SECRETS IN PRODUCTION

Environment variables: never in the code

What you store locally in .env is stored in production as secrets in the platform's dashboard.

NEVER: hardcode API keys directly in the source code.

NEVER: push the .env file to GitHub — always add it to .gitignore.

ALWAYS: create a .env.example that documents which variables are needed, without the real values.

AI can list every variable your project needs: "What environment variables does this project need to run in production?"

CHAPTER 02

Deploying step by step

From zero to a public URL in under 5 minutes with Vercel.

DEPLOYING ON VERCEL

Your first public URL in 6 steps

  1. 01

    Create an account

    vercel.com with GitHub. No credit card required. Unlimited free tier for personal projects.

  2. 02

    Import Project

    Add New → Import Git Repository. Connect your GitHub account and select the repository.

  3. 03

    Configure the framework

    Vercel detects Next.js automatically. Confirm the suggested configuration.

  4. 04

    Environment variables

    Settings → Environment Variables. Add the variables from .env.example before deploying.

  5. 05

    Deploy

    Click Deploy. Automatic build: installs dependencies, compiles. Real-time logs.

  6. 06

    Live URL

    In 1-2 minutes you have yourapp.vercel.app live with HTTPS enabled. Share it with anyone.

CONTINUOUS INTEGRATION AND DEPLOYMENT

Push, and you're done: how CI/CD works

CI/CD eliminates manual deploys. Every push to the main branch updates your production. AI can set up this pipeline for you.

Total time: ~2-3 minutes from push until users see the new version.

CHAPTER 04

Monitoring and security

Knowing when something breaks before your users tell you.

BASIC MONITORING

Three tools to know everything works

  • 01

    UptimeRobot — Watches your URL every 5 minutes

    Automatic email if your app goes down. Free for 50 monitors. Setup: 2 minutes. Ideal as your first line of alerts.

  • 02

    Vercel Logs — Your first stop for any error

    Dashboard with real-time logs and build errors. Accessible from the Vercel panel with nothing to install.

  • 03

    Sentry — Captures errors with full context

    Free tier available. Captures JavaScript errors with stack trace, affected user, and context. AI can set up Sentry in your project in minutes.

BASIC SECURITY

Five things you need from day one

  • 01

    Automatic HTTPS

    Vercel sets it up on its own. Your URL is always https://. No action required on your part.

  • 02

    Environment variables for every secret

    Never in the code, never on GitHub. Vercel dashboard → Environment Variables.

  • 03

    Rate limiting on your API

    Protects your API from abuse and unexpected OpenAI costs. AI can add it with express-rate-limit in under 5 minutes.

  • 04

    Validation of user inputs

    AI should always validate data coming from the user before processing it or sending it to another API.

  • 05

    Periodic dependency review

    Periodically ask AI: "Check whether this project has any dependencies with known vulnerabilities."
